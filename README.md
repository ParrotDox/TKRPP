# Анализ существующего алгоритма действий
#### Глоссарий страницы
- Контрольная точка - место в учебных материалах, на которых остановился студент в последний раз
#### Анализ алгоритма изучения материалов
В текущих условиях обучения студентам требуется открывать огромное количество обучающих материалов в word, pdf форматах, изучать их и выписывать ключевые моменты. 
Такой способ просмотра материала хоть и удобен, но имеет следующие недостатки:
- Небольшие, но огромные затраты. Открытие файлов и поиск контрольной точки в материалах после каждой перезагрузки компьютера ведет к хоть и небольшой, но немаловажной задержке. Одно открытие и поиск информации может занять около 5-10 секунд, но суммарно, сложив все открытия, полученные значения потраченного времени могут увеличиться
- Научный стиль. Огромное количество научного текста сложно запоминается студентами. Для понимания сути учебных текстов, требуется обрабатывать материал через призму "студента"
- Недостаток времени. Создание конспектов зачастую ведется традиционным способом - написанием в тетради или современным - написанием цифрового материала. Оба способа отнимают жизненно важное для студента время, что направляют его фокус не на изучение материала, а на обработку и лаконичную передачу материала
Таким образом, основными недостатками преобладающего среди студентов подхода конспектирования и практики материала являются недостаток времени и научный стиль, скрывающий основную суть теории сложными синонимами слов.



# I/O данные программы
#### Входные данные
- Файлы с расширением:
	- word
	- txt
	- pdf
- Команды пользователя на формирование корректного промпта:
	- TextInput: Указание пользователем требуемых терминов и тем для формирования конспекта/задания
	- Указание пользователем стиля, тона написания текста конспектов/заданий
(сохранить исходный, краткий, "на пальцах")
	- Проверка/валидация (строгая/простая)
	- Тип выдаваемого результата (конспект, задание, смешанный)
- Общие команды:
	- Команда выбора окна создания промпта для ИИ
	- Команда отправки промпта ИИ
	- Команда сохранения результата промпта в локальном хранилище
	- Команда просмотра сохраненных результатов
	- Команда прикрепления тегов для сохраненных результатов ИИ (для сортировки по темам)
	- Команда печати полученных результатов на принтере
#### Выходные данные
- Результат поданного на вход промпта от ИИ (данные о карточке)
	- Текстовые конспекты
	- Текстовые карточки с заданиями
	- Ключевые термины
	- Тема
	- Дата и время генераци
- Рекомендации по сохранению результата, повтора генерации или удалению полученного результата ИИ
- Рекомендация по печати материалов на принтере



# Функциональные требования
1. Работоспособность (ярлык есть и слава Келемвору)
2. Система должна принимать входные учебные материалы в форматах PDF, DOCX, TXT
	- [ ] должна уметь распознавать текст, парсить его из pdf в текст
3. Система должна передавать в промпт ИИ параметры, выбранные пользователем:
	- [ ] Уровень детализации (кратко, подробно, тезисно);
	- [ ] Целевая аудитория/сложность (школьник, студент);
	- [ ] Формат вывода (конспект, тестовые вопросы, открытые задания, флэш-карточк и).
4. Система должна выполнять базовую автоматическую проверку ответа ИИ (проверка на полноту структуры, отсутствие пустых полей и соответствие формату JSON;
5. Система должна предоставлять пользователю интерфейс редактирования: возможность исправить текст конспекта или отредактировать сгенерированные задания перед их сохранением;
6. Система должна сохранять сгенерированные конспекты, наборы карточек и результаты прохождения упражнений в локальную базу данных (сериализация в JSONе) на устройстве пользователя;
7. Система должна обеспечивать возможность просматривать, искать, фильтровать по предметам/тегам, редактировать и удалять ранее сохраненные конспекты и карточки без подключения к сети;
8. Система должна формировать печатную форму для:
	- [ ] Текстового конспекта (с нормативными отступами и заголовками);
	- [ ] Набора карточек/заданий (в виде сетки/шаблона для удобной двухсторонней разрезки).
9. Система должна поддерживать экспорт готовых материалов в форматы PDF, WORD и TXT для локальной печати или передачи на другие устройства.



# Нефункциональные требования
- Для доступа к ИИ система должна быть подключена к интернету, но основные функции системы (кроме генерации засчет ИИ) должны быть доступны и без интернета
- Время генерации карточки должно быть приемлимым - около 20 секунд
- Результаты генераций (конспекты и задания) должны храниться локально на устройстве
- Ошибки приложения и предупреждения должны иметь понятный смысл и иметь соответствующие действия для принятия решений
- Приложение должно работать на устройствах, поддерживающих современные веб-браузеры и веб-технологии
- Интерфейс системы должен разделятся на тематические разделы. Должна соблюдаться логичность и последовательность в навигации
- Главный экран должен предоставлять доступ к хранилищу и к генерации на основе ИИ



# Требования к информационному обеспечению
- Система должна хранить историю действий с возможностью их отмены
- Система должна хранить конспекты и задания с соответствующими метаданными
- Метаданные должны отражать дату создания, теги, ключевые слова конспекта/задания
- Данные должны быть структурированы и представлены в JSON формате



# Требования к программному обеспечению
- Разрабатываемая система должна работать в современных браузерах
- Разрабатываемая система должна уметь парсить текстовые файлы формата PDF, TXT, WORD при помощи специальной библиотеки
- Для общения к ИИ система обязана использовать специальный API
	- Для обращения к API ипользуется один из представленных ЯП от ИИ-компании
- Хранение данных о пользователе и запросах должно хранится в JSON формате
	- Чтение и запись данных должна проводится средствами ЯП, поддерживающего JSON сериализацию и десериализацию
- Система должна содержать UI файлы, выполненный при помощи одного из программных способов: специальные библиотеки, языки разметки, стилей и иные технологии
- Система должна использовать программную библиотеку для печати конспектов/заданий на принтере
- Инструкции и алгоритмы должны быть выполнены на одном из ЯП
