# План первого спринта

**Проект:** https://github.com/ParrotDox/TKRPP.git
**Даты:** 03.11.2026 – 17.11.2026 (две недели).
**Состав:** Максим, Данил, Александр, Егор.

## Цель спринта

> **К концу спринта пользователь открывает приложение в браузере, загружает учебный файл (PDF/TXT) и видит извлечённый из него текст.**

## Задачи спринта

| ID | Задача | История | Исполнитель | Условие завершения | Зависимости | SP |
|---|---|---|---|---|---|---|
| T-01 | Вёрстка экрана генерации | US-03-02, US-03-03 | Егор | Зона загрузки, параметры генерации, поле промпта, кнопка и область результата сверстаны; страница тянется по ширине окна | — | 3 |
| T-02 | Каркас бэкенда на ASP.NET | US-03-02 | Максим, Александр | Проект Minimal API запускается на `localhost`, раздаёт файлы из `wwwroot` (их пишет T-01), `GET /api/health` отвечает 200 | — | 3 |
| T-03 | Формат JSON-запросов и ответов | US-03-02 | вся команда | Формат запроса (файл → текст) и ответа записан в [module-interfaces.md](../architecture/module-interfaces.md), все участники согласны | — | 2 |
| T-04 | Отправка файла и показ текста в браузере | US-03-02 | Егор | Выбранный PDF/TXT уходит на `/api/parse`, текст появляется на странице; ошибка видна пользователю | T-01, T-03, T-05 | 2 |
| T-05 | Распознавание текста из PDF/TXT | US-03-02 | Данил | Валидный PDF/TXT → 200 + текст; битый/пустой файл → 400 с кодом ошибки | T-02, T-03 | 5 |
| T-06 | Каркас интерфейса (шапка, меню, главный экран) | US-0N | Егор | По страницам можно переключаться; главный экран показывает мок-список колод/карточек; состояния «пусто/загрузка/ошибка» отрисованы | T-01 | 3 |
