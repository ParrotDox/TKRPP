# Бэклог продукта

**Лабораторная работа № 4.** Упорядоченный по приоритету список работ.
**Источники:** пользовательские истории и MoSCoW из лаб. № 2 ([requirements](../requirements/user-stories.md), [moscow.md](../requirements/moscow.md)); технические задачи — из модулей и связей лаб. № 3 ([architecture](../architecture/modules.md), [module-interfaces.md](../architecture/module-interfaces.md)).

В перечень включены только **Must-have** истории — ядро MVP. Should/Could-истории сознательно не расписываются.

## Технические задачи (из архитектуры лаб. № 3)

| Тех. задача | Модуль | Спринт | Комментарий |
|---|---|---|---|
| Каркас ASP.NET Minimal API (localhost, CORS, health-эндпоинт) | — | 1 | Поле для остальных эндпоинтов. |
| Каркас минимального UI (шапка, навигация, главный экран на моках) | UI | 1 | Основа для следующих экранов. |
| JSON-контракт UI ↔ Backend (parse / generate) | UI ↔ Все модули | 1 | Интерфейс связи из лаб. № 3; схема генерации резервируется под спринт 2. |
| PDF/TXT-парсер (`PdfPig`) — выбор библиотеки и реализация | Обработка документов | 1 | OCR и DOCX — позже. |
| Эндпоинт генерации (промпт + запрос к ИИ + валидация JSON) | Взаимодействие с ИИ | 2 | Таймаут 30 с, коды ошибок. |
| Хранилище SQLite: схема `Decks`, `Cards`, `Tags`, `History` + DAL | Локальное хранение | 2 | База для CRUD. |
| OCR-модуль (Tesseract.NET) | Обработка документов | 3+ (вне MVP) | Фото и сканы — после текстовых форматов. |
| DOCX-парсер (`DocumentFormat.OpenXml`) | Обработка документов | 3+ (вне MVP) | После устойчивого PDF/TXT. |
