# Связи и интерфейсы модулей

**Источник:** лабораторная работа № 3 (экспорт Anytype от 03.11.2026). Эти связи определяют **зависимости задач** в планах спринтов ([sprint-01.md](../planning/sprint-01.md), [sprint-02.md](../planning/sprint-02.md)) — задача, реализующая приёмную сторону связи, не может быть начата раньше задачи, реализующей передающую.

| Откуда | Куда | Назначение связи | Способ взаимодействия | Информация и ожидаемый результат |
|---|---|---|---|---|
| Модуль пользовательского интерфейса (UI) | Модуль обработки документов | Извлечение текста из загруженных пользователем файлов и фотографий | Локальный HTTP API (JSON) | **Передаётся:** загруженный файл или изображение (PDF, DOCX, TXT, PNG, JPG). **Ожидаемый результат:** распознанный текст единой строкой, возвращаемый в UI для отображения. |
| Модуль обработки документов | Модуль взаимодействия с ИИ | Запрос на генерацию конспекта и заданий по параметрам пользователя | Локальный HTTP API (JSON) | **Передаётся:** распознанный текст и настройки промпта (стиль, детализация, формат вывода). **Ожидаемый результат:** валидированный структурированный конспект с заданиями для предпросмотра и редактирования. |
| Модуль взаимодействия с ИИ | Внешний сервис ИИ (LLM Provider API) | Получение сгенерированных учебных материалов от нейросети | Сетевой HTTPS API (REST) | **Передаётся:** системный промпт с исходным текстом и требованием ответа в JSON-формате. **Ожидаемый результат:** ответ ИИ, проверяемый модулем на корректность структуры перед отдачей в UI. |
| Модуль пользовательского интерфейса (UI) | Модуль управления данными и колодами | Сохранение, редактирование, удаление, поиск и экспорт карточек/колод | Локальный HTTP API (JSON) | **Передаётся:** команды пользователя, редактируемый текст, поисковые фильтры и теги. **Ожидаемый результат:** актуальный список колод/карточек, подтверждение операции или файл экспорта. |
| Модуль управления данными и колодами | Модуль локального хранения (Persistence) | Чтение и запись пользовательских данных в базу данных | Внутренний программный вызов | **Передаётся:** программные объекты-модели (колоды, карточки, теги) или параметры выборки. **Ожидаемый результат:** выполнение SQL-запросов к SQLite, получение записей или подтверждение сохранения. |

## Каркас JSON-контракта (parse — спринт 1, generate — спринт 2; уточняется задачей T-03)

- **`POST /api/parse`** — файл (multipart) → `{ "text": "..." }`; при ошибке — код ошибки (битый файл, пустой файл).
- **`POST /api/generate`** — `{ "text": "...", "promptSettings": { "detailLevel": "...", "writingStyle": "...", "outputFormat": "...", "userPrompt": "..." } }` → ответ ИИ в JSON со строгой схемой: `{ "topic", "summary", "conspect", "tasks", "keywords" }`; при ошибке — структурированный код (`ERR_NETWORK`, `ERR_TIMEOUT`, `ERR_VALIDATION`).
