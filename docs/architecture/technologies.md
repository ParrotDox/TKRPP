# Обоснование выбора технологий и инструментов

**Источник:** лабораторная работа № 3 (экспорт Anytype от 03.11.2026).

| Технология / инструмент | Где и для чего используется | Почему подходит проекту | Существенные ограничения и компромиссы |
|---|---|---|---|
| **C# / .NET (8.0+)** | **Бэкенд:** бизнес-логика, парсинг, OCR, работа с БД и API ИИ. | Высокая скорость I/O, отличные библиотеки, опыт команды. | Требует .NET Runtime на ПК (решается Single-File сборкой). |
| **ASP.NET Core Minimal API** | **Транспорт:** HTTP-эндпоинты для связи JS с C#. | Легковесность, скорость работы, встроенный DI. | Группировка роутов вручную, без встроенной инфраструктуры MVC. |
| **JS / HTML5 / CSS3** | **Фронтенд:** UI, формы ввода, вёрстка печатных карточек. | Быстрая разработка интерфейса и гибкая печатная вёрстка. | Отсутствие строгой типизации в чистом JS. |
| **Браузер (Chrome / Edge / Firefox)** | **Среда выполнения UI:** пользователь открывает веб-приложение по адресу `localhost` в обычном браузере. | Отдельная оболочка (Electron/WebView2) не нужна: меньше вес сборки, зависимостей и потребление ОЗУ; кроссплатформенность «из коробки». | Нужно держать вкладку браузера открытой; поведение зависит от версии браузера (ориентир — актуальные версии). |
| **SQLite + EF Core / Dapper** | **Локальная СУБД:** хранение колод, карточек и тегов на диске. | Легконастраиваемая база в одном файле `.db`. | Блокировка БД при параллельной записи (не критично для 1 пользователя). |
| **PdfPig / OpenXml** | **Парсинг:** извлечение текста из PDF и DOCX. | Локальная обработка без отправки файлов в сеть, высокая скорость. | Сложность парсинга форматированных таблиц и защищённых PDF. |
| **Tesseract.NET / Win OCR** | **OCR:** распознавание текста с фото (`.png`, `.jpg`). | Бесплатная локальная обработка на русском и английском. | Чувствительность к качеству фото и плохому почерку. |
| **AI-провайдер** | **ИИ-сервис:** генерация конспектов, тестов и карточек. | Гарантия JSON-формата (Structured Output), высокое качество текста. | Зависимость от интернета, платные токены, задержки ответа (до 15–20 сек). |
