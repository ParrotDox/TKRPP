# Функциональные требования

**Источник:** лабораторная работа № 2. Смежные документы: [user-stories.md](user-stories.md), [non-functional-requirements.md](non-functional-requirements.md), [moscow.md](moscow.md).

## Функции пользователя

### Управление созданием карточки

- Загрузка учебных материалов для конспектирования.
- Настройка промпта для ИИ:
  - Уровень детализации (кратко, подробно);
  - Стиль написания (разговорный, официальный);
  - Формат вывода (конспект, вопрос-ответ);
  - Текстовое поле для ввода пожеланий.
- Генерация материалов карточки на базе ИИ.
- Сохранение учебной карточки (после генерации).

### Управление колодой

- Создание колоды.
- Редактирование колоды:
  - Название колоды;
  - Теги колоды.
- Просмотр колоды:
  - Поиск карточек по метаданным;
  - Сортировка учебных карточек.
- Удаление учебной карточки (из колоды).
- Уничтожение колоды.
- Экспорт/импорт колоды в файловом формате.

### Управление готовой учебной карточкой

- Редактирование учебных карточек:
  - Теги карточки;
  - Название карточки;
  - Учебный материал карточки;
  - Summary карточки;
  - Ключевые слова.
- Уничтожение карточки.
- Печать карточки при помощи принтера.
- Экспорт материалов карточки.

## Функции системы (автоматические)

- **Парсинг исходных данных:**
  - Текст из файлов (pdf, word, txt);
  - Распознавание текста с изображений при помощи модуля OCR.
- **Формировать карточку по запросу на базе ИИ:**
  - Конспект;
  - Метаданные.
- **Выполнять проверку ответа ИИ:**
  - Проверка структуры JSON-ответа;
  - Проверка наличия обязательных полей (Summary, Конспект, Задания, Ключевые слова, Тема);
  - Проверка валидности формата.
