# Пользовательские истории

**Проект:** «Приложение для автоматизации отработки и конспектирования учебных материалов на основе ИИ» (ТКРПП).
**Репозиторий:** https://github.com/ParrotDox/TKRPP.git
**Источник:** лабораторная работа № 2 (материалы команды, экспорт Anytype от 03.11.2026).

**Правки при копировании в репозиторий:**
- приведено к чистому Markdown (убрана служебная шапка Anytype);
- историям присвоены явные идентификаторы US-01-01…US-01-06, US-02-01…US-02-05, US-03-01…US-03-05 (в исходнике части ID подразумевались по порядку);
- **добавлены отсутствовавшие критерии приёмки US-03-01 и US-03-04** — они нужны для планирования спринта 2 и для тестирования (лабораторная № 5).

## Как писались истории (INVEST, кратко)

- **Independent** — история описывает независимую функцию, которую можно разрабатывать и тестировать отдельно.
- **Negotiable** — историю обязательно обсуждает команда.
- **Valuable** — функция несёт реальную ценность пользователю.
- **Estimable** — историю можно оценить по объёму и трудоёмкости.
- **Small** — история краткая и ёмкая.
- **Testable** — у истории есть проверяемые критерии приёмки.

## Кто пользователь и какая проблема

**Пользователь:** человек, занимающийся самообучением (студент, школьник).

**Проблема:** контрольная точка — место в учебных материалах, на котором остановился студент в последний раз.

Сегодня студентам приходится открывать огромное количество материалов в Word/PDF, изучать их и выписывать ключевые моменты. Недостатки такого подхода:

- **Небольшие, но огромные затраты.** Открытие файлов и поиск контрольной точки после каждой перезагрузки компьютера — задержка по 5–10 секунд на одно открытие, суммарно заметные потери времени.
- **Научный стиль.** Большой объём научного текста плохо запоминается; чтобы понять суть, требуется «перевод» материала на язык обучающегося.
- **Недостаток времени.** Конспектирование (рукописное или электронное) отнимает время: фокус уходит не на изучение материала, а на его обработку и переписывание.

Программа должна решать эти недостатки настраиваемой автоматизацией конспектирования.

## Критерии приёмки

### US-01-01

Как студент, я хочу иметь возможность создавать и удалять колоду, чтобы организовать карточки по темам.

1. Кнопка «Создать колоду» доступна на главном экране; при нажатии открывается модальное окно с полем ввода названия.
2. После подтверждения создания колода появляется в общем списке.
3. Кнопка «Удалить» (или иконка корзины) доступна в меню настроек конкретной колоды.
4. При нажатии «Удалить» появляется окно подтверждения («Вы уверены, что хотите удалить колоду и все её карточки?»):
   - при подтверждении колода безвозвратно удаляется из списка;
   - при отмене окно закрывается, колода остаётся на месте.

### US-01-02

Как студент, я хочу иметь возможность редактировать метаданные колоды.

1. В настройках колоды доступны для редактирования поля: «Название», «Описание» и «Теги».
2. Поле «Название» не может быть пустым:
   - при попытке сохранить пустое название система выдаёт ошибку валидации и блокирует сохранение.
3. Теги отображаются в виде цветных меток под названием колоды в общем списке.
4. Изменения метаданных сохраняются при нажатии кнопки «Сохранить» (или галочки подтверждения).

### US-01-03

Как студент, я хочу иметь возможность добавлять и удалять карточку из колоды.

1. Внутри колоды есть кнопка «Добавить карточку», открывающая список всех карточек из общего хранилища с чекбоксами.
2. Выбранные карточки добавляются в конец текущей колоды.
3. Каждая карточка внутри колоды имеет кнопку «Убрать из колоды» (крестик):
   - нажатие убирает карточку из текущей колоды, но **не удаляет** её из общего хранилища.
4. При попытке добавить карточку, которая уже есть в колоде, система блокирует повторный выбор или выдаёт уведомление «Карточка уже добавлена».

### US-01-04

Как студент, я хочу иметь возможность сортировать колоду.

1. В шапке экрана колоды есть список «Сортировка» с опциями:
   - «По дате добавления (сначала новые)»;
   - «По дате добавления (сначала старые)»;
   - «По алфавиту (А-Я)».
2. При выборе опции список карточек мгновенно перестраивается.
3. Выбранная сортировка сохраняется в локальных настройках и применяется по умолчанию при следующем входе в колоду.

### US-01-05

Как студент, я хочу иметь возможность поиска в колоде.

1. В верхней части экрана колоды есть строка поиска с иконкой лупы.
2. Поиск выполняется динамически по мере ввода (без Enter) по названию и тегам карточек.
3. Если ничего не найдено, отображается сообщение «Карточки не найдены» и кнопка «Сбросить фильтр».
4. При очистке строки поиска полный список карточек колоды восстанавливается.

### US-01-06

Как студент, я хочу иметь возможность импорта/экспорта колоды.

1. В меню колоды доступны две отдельные кнопки: «Экспорт» и «Импорт».
2. «Экспорт» генерирует JSON-файл с метаданными и текстом всех карточек и инициирует его скачивание.
3. «Импорт» открывает системное окно выбора файла:
   - поддерживаются только файлы валидного формата экспорта;
   - при выборе некорректного файла выдаётся ошибка «Неверный формат файла».
4. При успешном импорте создаётся новая колода; если колода с таким именем уже существует, предлагается переименование (например, дописать «копия»).

### US-02-01

Как студент, я хочу иметь возможность редактировать учебные материалы карточки.

1. В режиме просмотра карточки есть кнопка «Редактировать», открывающая текстовый редактор с содержимым.
2. Редактор поддерживает базовое форматирование: жирный, курсив, подчёркивание; маркированные и нумерованные списки; заголовки разных уровней.
3. Изменения сохраняются при потере фокуса или по кнопке «Сохранить».
4. При закрытии редактора с несохранёнными изменениями появляется модальное окно: «Сохранить изменения», «Не сохранять», «Отмена».

### US-02-02

Как студент, я хочу иметь возможность редактировать метаданные карточки.

1. В настройках карточки доступны поля: «Название», «Описание» и «Теги».
2. Поле «Название» не может быть пустым — при попытке сохранить выдаётся ошибка валидации.
3. Теги добавляются через поле ввода с автодополнением: новые создаются по Enter, удаление — по крестику на метке.
4. Теги отображаются в виде цветных чипсов под названием карточки в общем списке и внутри колоды.

### US-02-03

Как студент, я хочу иметь возможность уничтожения карточки.

1. В меню карточки есть опция «Уничтожить карточку».
2. При нажатии появляется модальное окно подтверждения: «Вы уверены, что хотите уничтожить карточку? Это действие нельзя отменить».
3. При подтверждении карточка удаляется из общего хранилища и автоматически убирается из всех колод, куда была добавлена.
4. После удаления пользователь перенаправляется на главный экран или предыдущее окно.

### US-02-04

Как студент, я хочу иметь возможность экспортировать учебный материал карточки в файл.

1. В меню карточки есть опция «Экспортировать».
2. Открывается окно выбора формата: `.pdf` — для просмотра и печати; `.txt` — для редактирования в сторонних редакторах.
3. После выбора формата и нажатия «Скачать» система генерирует файл с именем на основе названия карточки и инициирует загрузку.
4. При ошибке генерации отображается уведомление «Не удалось экспортировать файл. Попробуйте ещё раз».

### US-02-05

Как студент, я хочу иметь возможность распечатать карточку.

1. В меню карточки есть опция «Печать» (иконка принтера).
2. Открывается системный диалог печати ОС с предпросмотром: карточка форматируется под A4, заголовки и списки сохраняют структуру.
3. По умолчанию элементы интерфейса исключаются из печати — печатается только содержимое карточки.
4. Если принтер не настроен, отображается уведомление «Принтер не найден. Настройте принтер в настройках системы».

### US-03-01 *(критерии добавлены при копировании — в исходнике отсутствовали)*

Как студент, я хочу иметь возможность сгенерировать карточку на основе учебных материалов, чтобы структурировать знания.

1. После подтверждения генерации система отправляет распознанный текст и настройки промпта в модуль ИИ и отображает индикатор загрузки (ожидание не более 30 секунд — см. нефункциональные требования).
2. Успешный ответ содержит обязательные поля: **Тема, Summary, Конспект, Задания, Ключевые слова**.
3. Сгенерированная карточка отображается в окне предпросмотра без сохранения в хранилище.
4. Если ответ ИИ невалиден или неполон (проверка структуры JSON), пользователь видит структурированное сообщение об ошибке и кнопку «Повторить генерацию»; данные пользователя не искажаются.

### US-03-02

Как студент, я хочу иметь возможность загрузить файлы учебных материалов, чтобы дать данные для генерации карточки на базе ИИ.

1. Элемент выбора файлов:
   - при нажатии открывается диалог выбора файлов;
   - при перетаскивании файлов в элемент они загружаются в программу.
2. Элемент удаления загруженных файлов (крестик — удалить все).
3. Элемент меняет визуальное состояние при наличии/отсутствии файлов (пояснение в обоих состояниях).
4. Формат входных данных: `pdf`, `txt`, `word`, изображение (опционально).

### US-03-03

Как студент, я хочу иметь возможность настраивать предпочтения генерации ИИ.

1. Радиокнопки:
   - уровень детализации (кратко/подробно);
   - стиль написания (разговорный, официальный);
   - формат вывода (конспект, вопрос-ответ).
2. Пользовательский промпт: текстовое поле для ввода пожеланий.

### US-03-04 *(критерии добавлены при копировании — в исходнике отсутствовали)*

Как студент, я хочу иметь возможность пересоздать сгенерированную карточку, чтобы ИИ исправил неточности.

1. В окне результата генерации есть кнопка «Пересоздать».
2. Повторный запрос выполняется с теми же загруженными материалами и текущими настройками; перед пересозданием настройки можно изменить.
3. Предыдущий (несохранённый) результат полностью заменяется новым; частично отображённые старые данные не появляются в новом результате.
4. Если предыдущий результат уже сохранён в хранилище, пересоздание не изменяет и не удаляет сохранённую карточку — создаётся новая карточка.

### US-03-05

Как студент, я хочу иметь возможность сохранить сгенерированную карточку.

1. Материал сохраняется в общее хранилище карточек (историю создания).
2. Возможно сохранение карточки в колоду по выбору:
   - колоды представлены списком кнопок;
   - кнопки колод индикативно подсвечиваются при выборе.
3. Есть кнопка подтверждения сохранения; после неё карточка появляется и в хранилище, и в выбранных колодах.
