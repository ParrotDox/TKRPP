# Приоритеты MoSCoW (бэклог продукта, основа)

**Источник:** лабораторная работа № 2.

| ID. Название процесса | Приоритет | Объяснение |
|---|---|---|
| **US-0N**. Просмотр сущности | **Must** | Базовая навигация, без неё невозможно взаимодействие с приложением. |
| **US-03-01**. Генерация карточки | **Must** | Функциональное ядро продукта: без генерации конспекта ИИ приложение не имеет ценности. |
| **US-01-01**. Создание/удаление колоды | **Must** | Без колод некуда структурировать карточки по темам. |
| **US-01-03**. Добавление/удаление карточки из колоды | **Must** | Базовая механика наполнения колоды контентом. |
| **US-02-03**. Уничтожение карточки | **Must** | Необходима для очистки хранилища от ошибочных данных. |
| **US-03-02**. Загрузка файлов материалов | **Must** | Ядро продукта: без исходных данных ИИ не может работать. |
| **US-03-05**. Сохранение сгенерированной карточки | **Must** | Завершающий шаг сценария работы с карточкой. |
| **US-03-04**. Пересоздание карточки | **Should** | Улучшает качество результата; на первых этапах достаточно простой повторной генерации. |
| **US-03-03**. Настройка предпочтений ИИ | **Should** | Улучшает запрос, но необязательно на первых этапах (возможна минимальная версия). |
| **US-01-02**. Редактирование метаданных колоды | **Should** | Важно для порядка и поиска, но необязательно на первых этапах. |
| **US-01-04**. Сортировка колоды | **Should** | Важно для порядка и поиска, но необязательно на первых этапах. |
| **US-01-05**. Поиск в колоде | **Should** | Критично при большом объёме, для первой версии допустим ручной скролл. |
| **US-02-01**. Редактирование материалов карточки | **Should** | Полезно для правки ИИ, но необязательно на первых этапах. |
| **US-02-02**. Редактирование метаданных карточки | **Should** | Важно для порядка и поиска, но необязательно на первых этапах. |
| **US-01-06**. Импорт/экспорт колоды | **Could** | Полезно для бэкапа, но не влияет на ежедневное использование одним студентом. |
| **US-02-04**. Экспорт карточки в файл | **Could** | Дополнительная ценность «поделиться», не обязательная для личного обучения. |
| **US-02-05**. Печать карточки | **Could** | Узкий сценарий, требующий сложной вёрстки под A4. |

Полный бэклог со спринтовой разбивкой — [docs/planning/backlog.md](../planning/backlog.md).
